# Security Policy

## Supported version

The production version deployed from the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Use GitHub's private security advisory reporting for this repository, or contact the repository owner privately through GitHub.

Include a clear description, affected route or component, reproduction steps, and any suggested mitigation. You will receive an acknowledgement as soon as practical. Please do not disclose the issue publicly until a fix is available.

## Security boundaries

Never include Supabase service-role keys, scheduler secrets, venue credentials, or customer data in issues, pull requests, screenshots, or logs.
